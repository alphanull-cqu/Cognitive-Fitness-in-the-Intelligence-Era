## 关于本书

人类长期依靠智能认识自然、组织能量并创造文明。如今，推动文明发展的智能本身也开始能够被构建、复制和持续改进。智能纪元的变化，不只在于工作效率提高，更在于社会获得和组织认知能力的方式正在改变。

随着AI能力增强，更多认知任务会交给外部系统完成。对于时间和精力有限的人，这种外包有充分理由。但任务完成得更好，不代表个人形成了更深的理解；能够调用强大的能力，也不等于已经拥有自己的判断和方向。

学习仍有两个彼此相连的理由：发展自身，以及参与世界。理解陌生事物、形成自己的看法、发现值得投入的方向，本身就是人的需要。学习也支持人参与任务、工作和共同生活，使自己的认识与他人的需要发生联系。即使AI能够给出更好的方案，人仍应有机会理解、表达和影响与自己有关的安排。

认知体能关注理解、判断与主体性，行动是主体性的一部分。教育需要帮助学习者形成这些能力，也需要通过评价引导学习方向、确认实际成长。当市场对人类劳动的需求发生变化，学习的价值不能只由就业回报决定；大学与公共支持还应持续提供探索、学习和参与的条件。

**这本书由我与AI合著。从问题的梳理、结构的调整到文字的反复修改，AI参与了写作过程。**

## 本书讨论的问题

- **智能不断增强，哪些任务会交给AI？** 从建模、求解与评价的复杂性出发，理解持续变化的自动化边界。
- **不必先学也能取得结果，学习为什么还值得发生？** 同时考察人的自身发展与参与世界的需要。
- **怎样在使用AI时形成自己的能力？** 将学习目标、AI训练伙伴、递进项目与学习评价联系起来，使项目和竞赛服务于理解、判断和自主行动。
- **如果社会需要的劳动者减少，人的成长由谁支持？** 讨论共同教育、大学责任与公共投入，并保留每个人选择生活方向的空间。

## 目录

1. **智能革命：这一次为什么不同**
   从能量利用与智能积累，走向能够构建和扩展智能的新时代。
2. **AI会替代什么？**
   分析任务与复杂性，理解AI承担更多活动的条件及其变化。
3. **认知体能：AI越强，人如何成长？**
   讨论认知外包后的学习理由，展开理解、判断与主体性的内涵。
4. **不要停止思考：如何与AI共生**
   讨论学习目标、AI支持、项目与竞赛，以及引导方向和确认成长的评价。
5. **保持为人**
   面对就业需求变化，讨论教育机会、大学与公共支持，以及人对自身生活的认可和选择。

另含前言、结语与参考文献。
